# 01 技术栈说明

## 总览

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 语言与运行时 | C# / .NET 8 | Windows 桌面成熟方案 |
| UI | WPF | XAML、数据绑定和原生绘图 |
| 架构 | MVVM | View、ViewModel、Service 分层 |
| MVVM 库 | CommunityToolkit.Mvvm 8.3.2 | 属性和命令源生成 |
| 前台监听 | Win32 P/Invoke | `SetWinEventHook` 等系统 API |
| 进程信息 | System.Diagnostics.Process | 零额外进程库 |
| 后台心跳 | System.Timers.Timer | 会话心跳和定时保存 |
| UI 刷新 | DispatcherTimer | UI 线程更新 |
| 持久化 | System.Text.Json | JSON 本地存储 |
| 系统托盘 | WinForms NotifyIcon | 零额外托盘依赖 |
| 测试 | xUnit 2.5.3 | 服务层和状态机测试 |
| 覆盖率 | coverlet.collector 6.0.0 | 测试覆盖率采集 |

## 选型理由

### .NET 8 与 WPF

项目只面向 Windows，需要长期后台运行、系统托盘和 Win32 API 互操作。WPF 与这些能力兼容稳定，也能延续参考项目的实现经验。

### CommunityToolkit.Mvvm

使用 `[ObservableProperty]` 和 `[RelayCommand]` 减少样板代码。ViewModel 不直接引用窗口对象，便于测试。

### System.Text.Json

MVP 数据规模有限，JSON 可以保持部署简单和数据可读。持久化层通过接口隔离，未来可以迁移到 SQLite。

### WinForms NotifyIcon

WPF 没有内置托盘控件。直接使用系统自带 WinForms NotifyIcon，比增加第三方库更适合单文件发布。

### WPF 原生图表

概览和统计图形以时间线、柱状图、排行为主，可使用 `ItemsControl`、`Canvas`、`Rectangle` 和 `Polyline` 实现。MVP 不引入重型图表依赖。

## 发布基线

- 运行目标：`win-x64`。
- 自包含：开启。
- 单文件：开启。
- Trim：关闭，避免破坏 WPF 反射。
- ReadyToRun：关闭，降低 WPF + WinForms 单文件组合风险。
