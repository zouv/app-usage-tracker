# 02 使用说明

## 环境要求

- Windows 10 或 Windows 11。
- .NET 8 SDK 或更高版本 SDK。
- Git Bash。

## 构建

```bash
sh manager.sh build
```

## 启动

```bash
sh manager.sh start
```

启动后显示主窗口；关闭窗口默认最小化到托盘。可在设置页修改关闭行为。

## 测试

```bash
sh manager.sh test
```

## 发布

新版本发布由 `/app-release` skill 编排，本地机械步骤为：

```bash
sh manager.sh release <version>
```

仅打包发布单文件（不升版本号）：

```bash
sh manager.sh pack
```

发布文件生成到：

```text
dist/
```

## 清理

```bash
sh manager.sh clean
```

## 文档检查

```bash
sh check-docs.sh
```

## 数据目录

正式功能实现后，默认数据目录为：

```text
%AppData%\AppUsageTracker\
```

计划包含：

```text
usage_config.json
activity_sessions.json
daily_aggregates.json
manual_corrections.json
logs\
```

## 使用流程

1. 在“软件管理”中扫描运行软件或手动添加可执行文件。
2. 启用软件监听。
3. 返回“概览”查看当前前台软件与今日统计。
4. 在“统计分析”切换日、周、月、年和全部时间。
5. 在“时间记录”补录或修正异常记录。
6. 在“设置”调整空闲阈值、开机启动、托盘、全局快捷键和隐私选项。

## 数据备份与导出

- 设置页可以创建或恢复 ZIP 备份。
- 时间记录页可以导出完整会话 CSV。
- 数据完整性检查会验证各 JSON 文件是否可以正常解析。

## 隐私

- 默认不持久化窗口标题。
- 隐私模式期间不产生正式活动会话。
- 所有数据默认仅保存在本机。
